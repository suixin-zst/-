# 台前 · Demo 排练清单

> 目标：3 分钟不超时、不空场、不解释技术细节。
> 排练至少 2 遍：一遍看流程，一遍卡时间。

---

## 一、角色与口令

| 角色 | 负责 | 不要做 |
|---|---|---|
| 主讲 | 讲故事、看评委、控节奏 | 不要盯着屏幕找按钮 |
| 操作 | 点页面、切窗口、递链接 | 不要在主讲说话时抢话 |

**交接口令**：

- 主讲说「先看商家端」→ 操作切商家窗口；
- 主讲说「主持人这边」→ 操作切主持人窗口；
- 主讲说「我们把账算一下」→ 操作切幻灯 7；
- 主讲说「下一场活动」→ 操作切幻灯 9。

只用这四句，不临时加口令。

---

## 二、T-60 分钟

- [ ] 线上 main 链接能打开，不是 localhost
- [ ] 两个账号都登录成功，角色正确
- [ ] 种子数据在：`林知遥`、`苏晚`、`新能源新车发布会`
- [ ] 商家窗口停在 `/merchant/gig/new`
- [ ] 主持人窗口停在 `/host/gigs`
- [ ] 幻灯打开到第 1 页，`→` 能翻
- [ ] 录屏备份能播放
- [ ] 手机热点测试过

## 三、T-30 分钟

- [ ] 完整走一遍，**不讲解**，只点
- [ ] 计时：0:30 / 1:00 / 2:30 / 3:00 四个点
- [ ] 超时就把「商家看人」压缩到 15 秒
- [ ] 检查弹窗 / 成功态 / 空态是否都能回退
- [ ] 关掉所有通知：微信、系统、浏览器

## 四、T-10 分钟

- [ ] 浏览器缩放 110%
- [ ] 隐藏书签栏
- [ ] 两个窗口并排：左商家，右主持人
- [ ] 幻灯全屏
- [ ] 桌面只留录屏文件
- [ ] 深呼吸；主讲先说第一句，操作再动鼠标

---

## 五、时间卡点

| 卡点 | 应该发生什么 | 超时处理 |
|---|---|---|
| 0:30 | 讲完微信群故事，切首页 | 砍掉一句细节 |
| 1:00 | 商家发单页面已打开 | 直接点「填入示例」 |
| 1:45 | 主持人已报名 | 跳过筛选，直接点第一条 |
| 2:10 | 商家已发起邀约 | 不滚作品，直接说报价 |
| 2:30 | 切商业模式幻灯 | 跳过对比动画 |
| 3:00 | 停在「下一场活动，从台前开始」 | 不再补充 |

---

## 六、备份三层

1. **线上 main**（首选）
2. **本地 `localhost:3200`**（第二层）
3. **录屏 `台前-demo-备份.mp4`**（第三层）

录屏要求：

- 1920×1080，全程 3 分钟；
- 包含一次完整闭环；
- 关键页面停留 2 秒以上；
- 文件名带日期，放桌面第一排。

---

## 七、排练后复盘（两遍之间）

- 哪一句让评委抬头了？
- 哪一步操作超过 5 秒？
- 有没有说「我们这个系统用了……」？删掉。
- 有没有说「其实还没做完」？删掉。
- 主讲和操作有没有互相等？加口令或减页面。

---

## 八、常见错误

| 错误 | 后果 | 改法 |
|---|---|---|
| 一上来讲技术栈 | 评委走神 | 先讲人，再讲产品 |
| 在页面上找按钮 | 空场 3 秒 | 操作提前把页面停好 |
| 解释每个功能 | 3 分钟讲不完 | 只讲核心闭环 |
| 说「我们还没做完聊天」 | 减分 | 说「正式版这里是实时会话」 |
| 结尾拖沓 | 来不及 Q&A | 停在金句，等提问 |
| 两人同时说话 | 听不清 | 主讲说，操作只点 |

---

## 九、Demo 结束后的 10 秒

- 页面停在 `林知遥` 主页或「已达成」状态；
- 主讲不要关窗口；
- 操作把线上链接发到群；
- 评委靠近时，直接指作品集和报价，不要重新讲一遍。
