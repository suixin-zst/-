## 02 · 痛点

- 主标题：**接一场主持，先过五道群。**
- 三个数字：
  - 7 个微信群，重复发简历
  - 30–50% 被群主 / 中介抽走
  - 0 份作品沉淀，每次都被当新人
- 引语：「每次接单，都像重新做一次新人。」

**视觉**：三个大数字，横向排开；底部引语用衬线大字。

## 03 · 解法

- 主标题：**把接单，搬回台前。**
- 三列：
  - 作品说话：婚礼 / 年会 / 发布会现场视频
  - 透明报价：时 / 半 / 全天，写清楚
  - 直接沟通：站内聊，不加微信
- 一句：**中介 30% → 台前 8%。**

**视觉**：三列卡片；8% 用金色大数字压底。
